# RTL 知识卡

实际模型输入位于 `knowledge/`：一张 ROOT 总则、六张主题叶卡，以及 catalog。叶卡覆盖边沿与状态、事件历史、握手、生命周期、数值范围及滚动窗口。

路由器依据公开题面选择最多两张叶卡，不按题号选卡。ROOT 与所选卡进入生成提示；引用是否逐字匹配单独记录，不把引用审计当功能判断。需求中的具体条款优先于通用卡片，路由短答也不能覆盖原始题意。

卡片的 SHA 和大小由 `prompt-inputs.lock.json` 绑定，组装器验证同一份内存字节。这里不包含测试题、参考答案、隐藏测试、历史分数或会话记录。修改卡片必须重新做版本与验证，不能直接绕过校验。

卡片能提示常见易错点，例如先扩展再运算、旧值与新值采样、脉冲保持和取消条件，但不能保证 RTL 已正确实现。最终仍以代码与独立测试的实际行为判断。
